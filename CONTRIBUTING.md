# Contributing to NOISE

NOISE is a **closed-source freeware** project. The source code is not public,
and code contributions or pull requests are **not accepted**.

## Bug reports are welcome

If you find a bug, please open an issue and include:

- the NOISE version you are using
- your operating system and version
- clear steps to reproduce the problem
- what you expected to happen
- what actually happened
- screenshots or logs if available

Please use the bug report issue template so the report includes the necessary
details.

## Pull requests

Please do not open pull requests. Unsolicited pull requests will be closed
without review.

## Feature requests

Feature requests are welcome as issues, but there is no guarantee that a
request will be implemented.

## Security issues

Please do not disclose security-sensitive issues publicly. Contact the author
directly first so the issue can be investigated and fixed.
